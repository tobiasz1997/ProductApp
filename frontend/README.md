# ProductApp Frontend

Angular version 21

## Requirements

- Node >= 20.19

## Extermanl API

The application downloads products from an external API. A key must be created from the [RapidAPI](https://rapidapi.com/letscrape-6bRBa3QguO5/api/real-time-amazon-data) website and added to [environment.ts](./src/environments/environment.ts) in place of the ***rapidKey*** field.

## Installation

To start a local development server, run:

```bash
npm i
```

and then
```bash
ng serve
```
