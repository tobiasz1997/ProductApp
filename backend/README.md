# ProductApp Backend

.NET version 9

## Requirements

- .NET 9
- Docker

### Installation

Before you run the project, you need to run *docker-compose.yml*
```bash
docker compose -f docker-compose.yml up
```
You can add flag *-d* to run containers in background
